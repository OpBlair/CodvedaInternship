## 💻 About the Project

This portfolio demonstrates my journey as a developer, my skills, and my projects. It includes:

- **Home:** Introduction and motivational quotes.  
- **About:** Personal bio and tech stack.  
- **Projects:** Detailed showcase of my work with live demos and GitHub links.  
- **Contact:** A contact form and social media links for collaboration opportunities.

The website is **responsive**, visually appealing, and easy to navigate.

---

## ✨ Features

- Responsive navigation with **active link highlighting**.  
- Animated **motivational quotes** on the homepage.  
- Interactive **projects section** with live demos and GitHub links.  
- Contact form with **instant client-side feedback**.  
- Smooth **fade-in animations** for content sections.  
- Mobile-friendly and fully responsive design.  

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Tailwind CSS  
- **JavaScript:** Vanilla JS for interactivity, quotes, and form handling  
- **Backend (Optional):** Contact form is frontend-only; can be extended with a server  
- **Databases:** PostgreSQL, MySQL (for showcased projects)  
- **Tools:** Git, Figma
