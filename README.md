### Level 2 (Intermediate)

**1. Interactive Calculator**  
- **Description:** A calculator with basic arithmetic and scientific functions built with React.  
- **Tech:** React, CSS  
- **Features:** Dynamic input handling, real-time calculations, responsive design.  
- **Live Demo:** [Calculator](https://calculator-ten-henna-61.vercel.app)  
- **GitHub:** [Calculator Repo](https://github.com/OpBlair/CodvedaInternship/tree/main/Level_2/calculator-app)

**2. To-Do List App**  
- **Description:** Lightweight task management app using LocalStorage for persistence.  
- **Tech:** HTML, CSS, JavaScript, LocalStorage  
- **Features:** Add, delete, complete tasks; persistent data in browser.  
- **Live Demo:** [To-Do List](https://todo-list-mu-tawny.vercel.app)  
- **GitHub:** [To-Do List Repo](https://github.com/OpBlair/CodvedaInternship/tree/main/Level_2/todo_list-app)
